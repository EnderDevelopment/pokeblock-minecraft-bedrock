# Pokeblock

Pokeblock is a Minecraft plugin that adds Pokémon to Minecraft Bedrock Edition, featuring functional systems, custom 3D models, animations, artificial intelligence, and Pokémon battle mechanics. This plugin is designed to enhance the Minecraft Bedrock Edition experience by integrating Pokémon into the game world, allowing players to catch, train, and battle with Pokémon.

## Install

1. Download the plugin from the GitHub repository.
2. Place the plugin file in the `plugins` folder of your Minecraft Bedrock Edition server.
3. Start or restart your Minecraft Bedrock Edition server.

## Use

1. Once the server is running, players can interact with the plugin using various commands and in-game mechanics.
2. Use the `/ciao` command to greet the player.
